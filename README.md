# خطفة - الخادم الخلفي (Backend)

خادم بسيط يستخدم مكتبة yt-dlp لاستخراج معلومات الفيديوهات من منصات
التواصل الاجتماعي (يوتيوب، تيك توك، انستغرام، فيسبوك، تويتر/X) وبثّها
مباشرة عند طلب التحميل، بدون تخزين أي ملفات على الخادم.

## نقاط الوصول (Endpoints)

- `GET /` — للتأكد أن الخادم يعمل
- `GET /info?url=<رابط الفيديو>` — يرجع عنوان الفيديو، الصورة المصغرة،
  المدة، والجودات المتاحة
- `GET /download?url=<رابط الفيديو>&format_id=<المعرف من /info>` —
  يبث ملف الفيديو مباشرة

## النشر على Render

1. أنشئ مستودعًا جديدًا على GitHub وارفع هذه الملفات (`main.py`,
   `requirements.txt`)
2. من لوحة Render، اختر **New → Web Service** واربطه بهذا المستودع
3. أمر البناء (Build Command): `pip install -r requirements.txt`
4. أمر التشغيل (Start Command):
   `uvicorn main:app --host 0.0.0.0 --port $PORT`
5. اختر الخطة المجانية (Free) واضغط **Create Web Service**

بعد اكتمال النشر، ستحصل على رابط شبيه بـ:
`https://khatfa-backend.onrender.com`

## اختبار سريع من المتصفح

الصق في شريط العنوان (بعد استبدال الرابط برابط خادمك الفعلي،
وما بعد url= برابط فيديو حقيقي):
```
https://khatfa-backend.onrender.com/info?url=رابط_فيديو_هنا
```

يجب أن يظهر لك نص JSON فيه عنوان الفيديو وقائمة الجودات.
